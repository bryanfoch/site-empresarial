# 🏢 Site Empresarial

Projeto de website empresarial desenvolvido utilizando HTML, CSS, JavaScript e PHP, com foco em apresentação institucional, responsividade e experiência visual moderna.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- Responsive Design
- Git & GitHub

---

## 🎯 Objetivo do Projeto

Desenvolver um site empresarial moderno e funcional para apresentação institucional, serviços e presença digital, aplicando conceitos de desenvolvimento Front-End e estruturação web.

---

## ⚙️ Funcionalidades

- Layout responsivo
- Carousel de imagens
- Navegação dinâmica
- Estrutura organizada
- Interface moderna
- Otimização visual
- Compatibilidade com diferentes dispositivos

---

## 📁 Estrutura do Projeto

```bash
├── carrousel/
├── img/
├── index.html
├── index.php
├── script.js
├── style.css
└── .hintrc
```

---

## 🛠️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/bryanfoch/site-empresarial.git
```

Acesse a pasta:

```bash
cd site-empresarial
```

Abra o arquivo `index.html` no navegador

ou utilize um servidor local como:

- XAMPP
- Live Server (VS Code)
- WAMP
- PHP Server
